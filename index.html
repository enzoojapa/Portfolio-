Python · Firebird · Dados Massivos

Cruzamento Ambulatorial x Hospitalar

Script em Python que cruza pacientes presentes na base Ambulatorial (DBF de 15GB) e Hospitalar (Firebird 1.5 de 3GB) com o mesmo procedimento e data. O banco antigo exigiu quebra de senha e engenharia reversa para acesso. O projeto possibilitou o bloqueio de AIHs duplicadas, evitando cobranças indevidas ao estado.
